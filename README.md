### ⚡ What is Lucky OneBlock?

**Lucky OneBlock** spawns you on a single floating Lucky Block in a pure void world. Mine it as fast as you want — the block instantly respawns in the exact same tick, triggering real random drops, surprises, traps, and rewards from [Simple Lucky Block](https://modrinth.com/mod/simple-lucky-block).

And best of all: **You can never fall into the void.**

---

### ✨ Features

* ⛏️ **Instant Block Replacement:** As soon as you break the Lucky Block at `(0, 64, 0)`, the drop triggers and a new Lucky Block regenerates immediately in the same server tick.
* 🛡️ **Anti-Void Safe Stand:** Automatic void-rescue catches you if you ever get pushed off by mobs or explosions, safely teleporting you back on top of the block.
* 💥 **Blast Protection:** TNT drops or Creeper explosions will never permanently destroy the OneBlock anchor.
* 🌌 **Dedicated World Preset:** Select **"Lucky OneBlock (Void)"** directly in the world creation menu to generate your island.
* 🎮 **Seamless Integration:** Powered by the official [Simple Lucky Block](https://modrinth.com/mod/simple-lucky-block) mod.

### 🚀 Quick Start

1. Install **Fabric Loader** (0.16.x+) and **Fabric API** for Minecraft 1.21.x / 1.21.11.
2. Put both **`luckyoneblock.jar`** and **[Simple Lucky Block](https://modrinth.com/mod/simple-lucky-block)** into your `mods` folder.
3. Start Minecraft, click **Create New World**, and select **World Type: Lucky OneBlock**.
4. Start mining!

---

### 📦 Building from Source

```bash
git clone https://github.com/exitishere42/lucky-oneblock.git
cd lucky-oneblock
./gradlew build
```

Built JARs will be located in `build/libs/`.
